Tutorial: Elemento C3D8 — Solido 3D Hexaedro Lineal (Paso a Paso)

C3D8 = Continuum 3D, 8-node hexahedron (notacion Abaqus)

Elemento fundamental para analisis 3D de solidos:

- 8 nudos

- 3 DOF por nudo (ux, uy, uz)

- 24 DOF totales

- Shape functions trilineales

- Integracion Gauss 2x2x2 = 8 puntos

Aplicaciones:

1. Zapatas como solidos 3D (no como shell)

2. Muros de contencion

3. Pedestales, dados de fundacion

4. Estructuras masivas (presas, tuneles)

5. Conexiones soldadas de acero

6. Anclajes en concreto

PASO 5) Jacobiano en un punto de Gauss

detJ = J11 · J22 · J33 = 500 · 500 · 500 = 125000000

PASO 10b) Esfuerzos sigma_zz — Color map estilo SAP2000

Calcular esfuerzos nodales via la relacion constitutiva:

sigma = D * epsilon

Para cubo bajo compresion uniforme: epsilon_zz = uz/Lz (en cada nudo)

Y por Poisson: epsilon_xx = epsilon_yy = -nu * epsilon_zz

sigma_zz = lambda*(eps_xx + eps_yy + eps_zz) + 2*mu*eps_zz

= lambda*(-2*nu*eps_zz + eps_zz) + 2*mu*eps_zz

= (lambda*(1 - 2*nu) + 2*mu)*eps_zz

= E*eps_zz (simplificacion para estado uniaxial)

Resumen

El elemento C3D8 captura:

1. Estado de esfuerzo 3D completo (σxx, σyy, σzz, τxy, τyz, τzx)

2. Efecto Poisson en 3 direcciones

3. Confinamiento lateral

4. Concentraciones de esfuerzo locales

Ventajas vs Shell:

- No hace asunciones de espesor pequeño

- Captura esfuerzos transversales

- Valido para cualquier geometria 3D

Desventajas vs Shell:

- 24 DOF por elemento (vs 12 del MITC4)

- Mallas 3D son 1-2 ordenes de magnitud mas grandes

- Requiere solvers sparse eficientes para ser practico

Aplicaciones reales en ingenieria civil:

- Zapatas masivas

- Pedestales de anclaje

- Dados de fundacion

- Muros de contencion gruesos

- Estribos de puente

- Presas de concreto

En SAP2000: Define Section Properties → Solid → "Solid" (C3D8 equivalente) En Abaqus: Element type C3D8 (exact match) En ANSYS: SOLID185 En ETABS: Solid elements en modo avanzado

 

Notacion Abaqus para elementos solidos

C3D4: Tetraedro 4 nudos (lineal, no recomendado — muy rigido) C3D10: Tetraedro 10 nudos (cuadratico, preferido para mallas irregulares) C3D8: Hexaedro 8 nudos (lineal) — ESTE TUTORIAL C3D8R: Hexaedro 8 nudos con integracion reducida (1 Gauss + hourglass control) C3D8I: Hexaedro 8 nudos con modos incompatibles (mejor en flexion pura) C3D20: Hexaedro 20 nudos (cuadratico, muy preciso pero caro) C3D20R: Hexaedro 20 nudos con integracion reducida
