Finite Element Method — From Frames to Plates

A Complete Tutorial with Symbolic Derivations and Visualizations

 

Part 1: History and Motivation

The Finite Element Method (FEM) was developed in the 1950s-60s by engineers at Boeing

(Turner, Clough, Martin, Topp — 1956) to analyze aircraft structures too complex for

classical methods. The key idea: divide a complex structure into simple elements

(bars, triangles, quads), solve each one, then assemble them together.

Part 5: From 1D to 2D — The Plate Element

For slabs and walls, we need 2D elements. The simplest is the 4-node quad (Q4).

Each node has 2 DOF (ux, uy) for plane stress, or 3 DOF (w, thetax, thetay) for plates.

Part 9: Summary

The FEM progression:

1. Bar (1D, axial) → trusses

2. Beam (1D, bending) → Hermite shape functions

3. Frame (1D, axial+bending) → portal frames, bridges

4. Plate Q4 (2D, bending) → slabs, walls, shells

5. 3D solids → dams, foundations, complex geometry

Each step adds DOFs and complexity, but the principle is the same:

K·u = F — assemble, solve, post-process.
