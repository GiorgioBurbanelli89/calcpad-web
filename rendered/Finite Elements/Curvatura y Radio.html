La formula κ = 1/R no la invento UNA sola persona.

Fue un proceso de 80 anos con 3 protagonistas:

 

1673 — Christiaan Huygens (holandes, 44 anos)

Huygens queria hacer un RELOJ DE PENDULO perfecto.

El problema: un pendulo circular NO marca el tiempo exacto.

Para resolverlo invento el CIRCULO OSCULADOR:

"En cada punto de una curva, hay un circulo unico que la BESA."

PARTE 1: Maneja un carro por una carretera

 

Imagina que manejas un carro. El VOLANTE controla la curvatura.

 

Caso 1: Volante recto → vas derecho

 

Caso 2: Volante girado poco → curva suave

 

Caso 3: Volante girado mucho → curva cerrada

 

Mas giro de volante = mas curvatura = curva mas cerrada.

Circulo grande → poco giro → curvatura pequena.

Circulo pequeno → mucho giro → curvatura grande.

PARTE 6: La viga como curva

 

Cuando una viga se dobla, su forma es una curva con curvatura κ = 1/R.

 

(a) Viga en reposo — fibras iguales: mp = nq

 

mp = nq: todas las fibras tienen la misma longitud.

 

(b) Viga en flexion — fibras cambian: mp < nq

 

Arriba (m→p): fibras se ACORTAN (compresion)

Abajo (n→q): fibras se ALARGAN (tension)
