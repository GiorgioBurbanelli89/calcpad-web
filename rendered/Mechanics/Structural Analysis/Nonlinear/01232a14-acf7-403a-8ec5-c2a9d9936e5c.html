Third order geometric nonlinearity analysis of a double-bar Biot truss

(solved by four different numerical methods)

Input data

Strut length - l = 2 m

Material - steel. Modulus of elasticity - E = 210 GPa

Cross section - circular with diameter Φ = 20 mm

Area - A = π · Φ24 = 3.141593 ·  ( 20 mm ) 24 = 3.141593 cm2

Axial stiffness - EA = E · A = 210 GPa · 3.141593 cm2 = 65973.44573 kN

Vertical force - Fy = 20 kN

Solution

Because of the symmetry, the horizontal displacement in the middle is u = 0 m .

The vertical displacement is the only unknown - v = ?

Since the system is linearly unstable, we use 3-rd order geometric nonlinearity theory for the solution. The equilibrium equations are then derived for the deformed state of the structure, as follows:

Length and elongation in deformed state

l′ ( v )  =    √  ( l + u ) 2 + v2 , Δl ( v )  = l′  ( v )  − l

Horizontal reaction - Fx ( v )  = EA · Δl  ( v ) l · l + ul′  ( v ) 

Vertical reaction - Fy ( v )  = EA · Δl  ( v ) l · vl′  ( v ) 

Vertical reaction derivative - F′yv ( v )  = EA · (1l −  ( l + u ) 2l′  ( v ) 3)

1. Fixed point iteration method

Relative strain - ε = Fy2 · EA = 20 kN2 · 65973.44573 kN = 0.0001515761

Relative precision - δmax = 10-4 = 0.0001

Initial value - v0 = 200 mm

We express the unknown vertical displacement at the middle joint as a function of the vertical force:

v =   1(1l − εv0)2 −  ( l + u ) 2 =   1(12 m − 0.0001515761200 mm)2 −  ( 2 m + 0 m ) 2 = 110.243898 mm

After calculating the above expression iteratively n = 13 times, we get:

v = 134.509002 mm

Relative error - δ = | v − v0 || v | = | 134.509002 mm − 134.498784 mm || 134.509002 mm | = 7.596427×10-5

2. Newton-Raphson′s method

Initial value - v0 = 200 mm

We repeatedly calculate the following expression:

v = v0 − 2 · Fy  ( v0 )  − FyF′yv  ( v0 )  = 200 mm − 2 · Fy  ( 200 mm )  − 20 kNF′yv  ( 200 mm )  = 106.92874 mm

After n = 4 iterations we get: v = 134.505588 mm

Relative error - δ = | v − v0 || v | = | 134.505588 mm − 134.506799 mm || 134.505588 mm | = 9.002841×10-6

3. Secant method

Slope reduction factor - α = 1

Initial value - v0 = 200 mm

Force value - Fy0 = 2 · Fy  ( v0 )  = 2 · Fy  ( 200 mm )  = 65.482732 kN

We calculate the first approximation using Newton-Raphson′s method

v1 = v0 − α · Fy0 − Fy2 · F′yv  ( v0 )  = 200 mm − 1 · 65.482732 kN − 20 kN2 · F′yv  ( 200 mm )  = 153.46437 mm

Force value - Fy1 = 2 · Fy  ( v1 )  = 2 · Fy  ( 153.46437 mm )  = 29.674898 kN

The next approximation is evaluated by the formula:

v2 = v1 − α ·  ( Fy1 − Fy )  · v1 − v0Fy1 − Fy0 = 153.46437 mm − 1 ·  ( 29.674898 kN − 20 kN )  · 153.46437 mm − 200 mm29.674898 kN − 65.482732 kN = 140.890936 mm

We continue the calculations iteratively until we reach convergence.

After n = 4 iterations we get: v2 = 134.505588 mm

Relative error - δ = | v2 − v1 || v2 | = | 134.505588 mm − 134.5058 mm || 134.505588 mm | = 1.570768×10-6

4. Solution with Calcpad (modified Anderson-Bjork′s method)

v = $Root{2 · Fy  ( v )  = Fy; v ∈ [0 mm; 200 m]} = 134.505588 mm
