Deflection and Rotation of Cantilever with Concentrated Load

Beam length - l = 3  m

Load - F = 50  kN

Second moment of area - I = 160000  cm4

Modulus of elasticity - E = 30  GPa

Functions of rotation and deflection along the beam

EI = E · I · 0.01 = 30 · 160000 · 0.01 = 48000

φ ( x )  = FEI · (l · x − x22)

d ( x )  = F2 · EI · (l · x2 − x33)

Maximum deflection

dmax = d  ( l )  · 103 = d  ( 3 )  · 103 = 9.375 mm

Maximum rotation

φmax = φ  ( l )  · 103 = φ  ( 3 )  · 103 = 4.6875 rad·10³
